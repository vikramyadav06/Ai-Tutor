# Playwright with Python

The first subject in the tutor's core: web test automation with Playwright, Python and pytest.

- `catalog.json`: modules, the subject's onboarding questions and plan rules
- `<module-id>/lesson.json`: the lesson (batches of small steps with revision notes)
- `<module-id>/exercises/`: starter files; `<module-id>/solutions/`: reference solutions
- `CURRICULUM.md`: the full outline
- `requirements.txt`: packages for this subject only. Install them when you start it:

```bash
pip install -r core/subjects/playwright-python/requirements.txt
playwright install --with-deps
```

Learners write their code in `my-work/<module-id>/`. Lesson format: `core/teaching/lesson-format.md`.
